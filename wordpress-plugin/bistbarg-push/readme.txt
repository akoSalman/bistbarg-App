=== Bistbarg App Notifications ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.1.0

ارسال اعلان به کاربران اپلیکیشن اندروید بیست‌برگ.

== نصب ==
1. پیشخوان وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل bistbarg-push.zip را انتخاب و نصب کنید.
2. افزونه را فعال کنید.
3. منوی «اعلان‌های اپ» در پیشخوان اضافه می‌شود.

== نحوهٔ کار ==
اپ هر ۳۰ ثانیه (وقتی باز است) و حدوداً هر ۱۵ دقیقه (وقتی بسته است) اعلان‌های جدید را از
/wp-admin/admin-ajax.php?action=bistbarg_notifications
می‌گیرد. به سرویس خارجی (مثل Firebase) و سرور جداگانه نیازی نیست.
