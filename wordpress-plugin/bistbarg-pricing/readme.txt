=== قیمت دلاری مدیا ===
Stable tag: 1.3.0
Requires PHP: 7.4

قیمت محصولات را به دلار وارد کنید؛ قیمت تومانی خودکار بر اساس نرخ دلار محاسبه می‌شود.

== نصب ==
1. افزونه‌ها ← افزودن ← بارگذاری افزونه ← bistbarg-pricing.zip ← نصب و فعال‌سازی.
2. ووکامرس ← «قیمت‌گذاری دلاری»: حالت نرخ (دستی یا خودکار) و تنظیمات را انتخاب کنید.
3. در صفحهٔ هر محصول، بخش «عمومی»، فیلد «قیمت دلاری ($)» را پر کنید.

== نرخ خودکار ==
منبع پیش‌فرض tgju است. اگر کار نکرد، یک API دلخواه با «مسیر مقدار در JSON» وارد کنید.
