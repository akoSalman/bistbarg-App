=== ورود با موبایل بیست‌برگ (کاوه‌نگار) ===
Stable tag: 1.0.0
Requires PHP: 7.4

ثبت‌نام و ورود مشتریان با شمارهٔ موبایل و کد پیامکی (OTP) از طریق کاوه‌نگار.

== نصب ==
1. افزونه‌ها ← افزودن ← بارگذاری افزونه ← bistbarg-otp.zip ← نصب و فعال‌سازی.
2. تنظیمات ← «ورود با موبایل»: کلید API و نام الگوی OTP را وارد کنید.
3. در پنل کاوه‌نگار یک الگوی تأیید (VerifyLookup) با متن شامل %token% بسازید،
   مثلاً: «کد ورود شما: %token%» و نامش را در تنظیمات بگذارید.
4. کد کوتاه [bistbarg_otp_login] را در یک صفحه بگذارید (مثلاً صفحهٔ «ورود»).

== API برای اپلیکیشن ==
POST /wp-json/bistbarg/v1/otp/request  { "phone": "0912..." }
POST /wp-json/bistbarg/v1/otp/verify   { "phone": "0912...", "code": "12345" }
